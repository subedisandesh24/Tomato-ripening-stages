# 🍅 Tomato Monitoring App

This Streamlit app uses YOLOv8 models to:
1. Detect tomato maturity stages (Red, Turning, Green).
2. Annotate videos with tomato detection.
3. Classify leaf diseases.
4. Estimate fruit weight and yield.

## 🚀 How to run locally
```bash
git clone https://github.com/<your-username>/tomato-monitoring-app.git
cd tomato-monitoring-app
pip install -r requirements.txt
streamlit run app.py
